Panda Go: learn Go & Baduk

Panda Go is a free, ad-free iOS app for learning the Go board game, also called Baduk or Weiqi. Beginners can play against six panda difficulty levels and practice capturing stones in 12 handmade puzzles.

01

Start learning the Go board game

Tap a panda to start playing. Panda Go is built for first-time players who want to explore the board game through play. Go, Baduk and Weiqi refer to the same game; this is not a programming language course.

02

Six difficulty levels for practice

Choose from six levels, from Wobbly Chick to Panda Master. Start with an easier opponent while learning captures, then try another level when you want a different challenge.

03

Twelve capture puzzles

Practice with 12 handmade capture puzzles. The feedback lets beginners try again without punishment, focusing each attempt on capturing stones rather than a long competitive match.

04

Learn captures, ko and scoring

Panda Go implements captures, ko, handicap stones and Chinese scoring. It is free and has no ads. Use the App Store listing for current device compatibility and download availability.

Frequently asked questions

Is Panda Go a free Go board game app for beginners?

Yes. Panda Go is free, has no ads and is designed for first-time Go players.

Are Go, Baduk and Weiqi the same board game?

Yes. These are different names for the same board game. Panda Go helps beginners learn it through play and capture puzzles.

How many difficulty levels does Panda Go have?

There are six difficulty levels, from Wobbly Chick to Panda Master.

Does Panda Go include Go capture puzzles?

Yes. It includes 12 handmade capture puzzles with feedback that lets you keep trying.

Where can I download Panda Go?
